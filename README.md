# Bloom Break / 解压花园

> 给高压职场人的 3 分钟解压花园。

一个原创的 Web 轻游戏 MVP：交换消除 + 压力托盘 + 花朵成长连锁。

## 技术栈

- Next.js 14 (App Router)
- React 18 + TypeScript
- Tailwind CSS
- localStorage（无后端、无登录）

## 开发

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。

## 玩法

- 8x8 棋盘，点击相邻方块交换消除
- 压力元素进入底部 7 格托盘，三个相同自动清空
- 花朵 🌱 → 🌼 → 🌸 → 爆炸，触发连锁
- 完成关卡获得花朵、阳光、水滴，累积到《我的花园》
